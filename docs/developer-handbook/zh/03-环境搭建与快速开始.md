# 3. 环境搭建与快速开始

## 3.1 前置要求

| 工具 | 版本 | 校验命令 |
|------|------|----------|
| JDK | 17+（CI 覆盖 17 / 21 / 25） | `java -version` |
| Maven | 3.6+，或使用仓库内置 wrapper | `./mvnw --version`（wrapper 3.3.4 → Maven 3.9.16） |
| Git | 任意较新版本 | `git --version` |
| IDE | 推荐 IntelliJ IDEA | — |

**库使用者**要求 Spring Framework 为 6.0.x – 7.0.x（`main` / 0.2.x 线）或 4.3.x – 5.3.x（`1.x` / 0.1.x 线）。

## 3.2 引入 BOM

在 `<dependencyManagement>` 中 import `microsphere-spring-dependencies`，此后各模块依赖无需写版本号。

```xml
<properties>
    <microsphere-spring.version>0.2.39</microsphere-spring.version>
</properties>

<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>io.github.microsphere-projects</groupId>
            <artifactId>microsphere-spring-dependencies</artifactId>
            <version>${microsphere-spring.version}</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
```

BOM 精确管理以下 7 个构件：`microsphere-spring-context`、`-web`、`-webmvc`、`-webflux`、`-jdbc`、`-guice`、`-test`。

## 3.3 只引入需要的模块

```xml
<dependencies>
    <!-- 核心：属性源、可监听 environment、TTL 缓存、配置绑定 -->
    <dependency>
        <groupId>io.github.microsphere-projects</groupId>
        <artifactId>microsphere-spring-context</artifactId>
    </dependency>

    <!-- Spring MVC 扩展（会自动带上 microsphere-spring-web） -->
    <dependency>
        <groupId>io.github.microsphere-projects</groupId>
        <artifactId>microsphere-spring-webmvc</artifactId>
    </dependency>

    <!-- 测试工具：仅 test 作用域 -->
    <dependency>
        <groupId>io.github.microsphere-projects</groupId>
        <artifactId>microsphere-spring-test</artifactId>
        <scope>test</scope>
    </dependency>
</dependencies>
```

集成说明：

- **Spring Boot** 用法完全一致——这些是原生 Spring Framework 扩展，把 `@Enable*` 注解放到任意
  `@Configuration` 类（或 Boot 启动类）上即可。
- 重量级三方依赖（p6spy、guice、tomcat-embed、zookeeper）**不会传递引入**，使用对应功能时需自行添加。

## 3.4 五分钟冒烟验证

```java
@Configuration
@EnableTTLCaching
@EnableWebMvcExtension                                  // Web 应用中
@ResourcePropertySource(name = "app", value = "classpath:/config/*.properties", autoRefreshed = true)
public class AppConfig {
}
```

```java
@Service
public class ProductService {

    @TTLCacheable(cacheNames = "products", expire = 300, timeUnit = TimeUnit.SECONDS)
    public Product findById(Long id) { /* ... */ }
}
```

启动应用并连续调用两次：300 秒内第二次命中缓存，条目到期后自动失效。

> 注意：`@TTLCacheable` 的 TTL 属性名是 `expire`（根 README 示例中的 `ttl = 300` 与实际代码不符）。

## 3.5 克隆与本地构建（贡献者）

```bash
git clone https://github.com/microsphere-projects/microsphere-spring.git
cd microsphere-spring

./mvnw package -DskipTests   # 环境自检，期望 BUILD SUCCESS
./mvnw verify                # 完整构建 + 测试
```

IDE 导入：打开根 `pom.xml`（IDEA：*File → Open → Open as Project*；Eclipse：*Import → Existing Maven Projects*）。
项目使用 `${revision}` 版本——调整模块结构后请重新导入 Maven 工程，保证 IDE 模块解析正确。
