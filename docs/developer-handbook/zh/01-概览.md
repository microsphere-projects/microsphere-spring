# 1. 概览

**Microsphere Spring** 是面向 Spring Framework 的模块化扩展库，解决生产环境 Spring 应用中的实际问题。所有能力都是
"插入即用"（drop-in）的：它增强既有 Spring 应用而不替换任何基础设施，并且全部功能都通过 `@Enable*` 注解显式开启
（opt-in）。

## 1.1 能力一览

| 能力 | 模块 | 入口 API |
|------|------|----------|
| Bean 并行预实例化（加速启动） | context | `ParallelPreInstantiationSingletonsBeanFactoryListener` |
| 可监听 `Environment`（拦截属性解析与 Profile 事件） | context | `EnvironmentListener`、`PropertyResolverListener` |
| 增强型 `@PropertySource`：通配符、排序、继承、自动刷新 | context | `@ResourcePropertySource` |
| YAML / JSON 属性源 | context | `@YamlPropertySource`、`@JsonPropertySource` |
| 默认属性源注入 | context | `@DefaultPropertiesPropertySource` |
| 配置 Bean 绑定（按前缀把 POJO 绑定并注册为 Bean） | context | `@EnableConfigurationBeanBinding` |
| 按条目 TTL 缓存 | context | `@EnableTTLCaching` + `@TTLCacheable` / `@TTLCachePut` |
| 事件与监听器拦截、异步监听、Bean 生命周期事件 | context | `@EnableEventExtension`、`BeanListener`、`ApplicationEventInterceptor` |
| `spring:` URL 协议（用 URL 访问资源与environment） | context | `SpringProtocolURLStreamHandler` |
| Web 端点注册表（汇聚 MVC、WebFlux、Servlet 元数据） | web + webmvc/webflux | `WebEndpointMapping`、`@EnableWeb*Extension` |
| 控制器方法拦截（AOP 风格钩子） | web + webmvc/webflux | `HandlerMethodInterceptor`、`HandlerMethodArgumentInterceptor` |
| 反向代理处理器短路（按端点 id 跳过匹配） | webmvc / webflux | `ReversedProxyHandlerMapping` |
| P6Spy JDBC/SQL 监控，透明包装现有 DataSource | jdbc | `@EnableP6DataSource` |
| Guice `@Inject` 接入 Spring 生命周期 | guice | `@EnableGuice` |
| 内嵌 Tomcat / 内嵌数据库 / 内嵌 ZooKeeper 测试支持 | test | `@EmbeddedTomcatConfiguration`、`@EnableEmbeddedDatabase`、`@EmbeddedZookeeperServer` |

## 1.2 分支与版本

| 分支 | Spring Framework 兼容范围 | 最新发布版 | 说明 |
|------|--------------------------|-----------|------|
| `main` | 6.0.x – 7.0.x | `0.2.39`（开发中 `0.2.40-SNAPSHOT`） | Java 17+，Jakarta EE（`jakarta.*` 命名空间） |
| `1.x` | 4.3.x – 5.3.x | `0.1.39` | Java 8+，`javax.*` 命名空间 |

版本号遵循语义化（`0.2.x`）；所有构件的 groupId 均为 `io.github.microsphere-projects`。
