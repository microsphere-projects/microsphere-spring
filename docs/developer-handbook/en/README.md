# Microsphere Spring Developer Handbook (English)

> Handbook for developers who **use** Microsphere Spring in their applications and who **contribute** to the library itself.
> Applies to the `main` branch: Spring Framework 6.0.x – 7.0.x, Java 17+, version `0.2.40-SNAPSHOT` in development.

9. [References](./09-references.md) — documentation, Javadoc, community links
